Especificación Funcional: HexaFinance
1. Módulo: Dashboard (Principal)

    Carga Inicial (GET /dashboard): * Lógica: Calcula LocalDate.now() para obtener mes/año actual. Sumariza transacciones del periodo.

        Retorno: Página dashboard.html completa.
Incluye dos botones prominentes: [+] Gasto/Ingreso y [+] Categoría.

    Acción: Filtro Rápido (GET /dashboard/summary):

        Input: month, year.

        Retorno: Fragmento HTML con las 3 tarjetas de balance.

        Target: #summary-container.
Acción HTMX: Abrir Formulario (GET /transactions/new):

    Trigger: Click en el botón [+].

    Retorno: Fragmento HTML con el formulario (inputs de monto, descripción, etc.).

    Target: Un contenedor vacío al final del HTML: #modal-overlay.

Acción HTMX: Guardar y Cerrar (POST /transactions):

    Retorno: 1. Alerta de "Éxito".
    2. Un fragmento vacío para "cerrar" el modal.
    3. Extra: HTMX permite disparar un evento para que el balance del dashboard se actualice automáticamente (HX-Trigger: update-balance).

2. Módulo: Transacciones

    Carga Inicial (GET /transactions): * Lógica: Recupera las ultimas 10-20 transacciones registradas por el usuario.

        Retorno: Página transactions.html.

    Acción: Crear (POST /transactions):

        Input: amount, description, categoryId, type.

        Retorno: Fragmento de alerta (Toast) + Limpieza de formulario.

    Acción: Filtrado Dinámico (GET /transactions/filter):

        Input: from, to, type, categoryIds[].

        Retorno: Fragmento de la tabla de transacciones (<tbody>).

        Target: #transaction-table-body.

3. Módulo: Categorías

    Carga Inicial (GET /categories): Lista de categorías (Globales + Privadas).

    Acción: Crear (POST /categories): * Input: name, iconName.

        Retorno: Alerta de éxito y actualización de la lista.

4. Módulo: Reportes

    Carga Inicial (GET /reports): Formulario con checkboxes de categorías y selectores de fecha.

    Acción: Generar Vista Previa (GET /reports/preview):

        Input: from, to, categoryIds[].

        Retorno: Lista sumarizada por categoría + balance neto + Botón "Descargar PDF".

        Target: #report-display-container.

    Acción: Descarga (GET /reports/download): (No es HTMX, es una descarga de archivo estándar).

5. Módulo: Perfil (Usuario)

    Carga Inicial (GET /profile): Datos actuales del usuario (menos password).

    Acción: Actualizar Datos (PUT /profile):

        Input: username, email.

        Retorno: Fragmento de "Perfil actualizado correctamente".

    Acción: Cambiar Password (PATCH /profile/password):

        Input: currentPassword, newPassword.

        Retorno: Notificación de éxito o error de validación.

6. Módulo: Admin (Gestión de Usuarios)

    Carga Inicial (GET /admin/users): Lista de todos los usuarios registrados en el sistema.

    Acción: Alternar Estado (PATCH /admin/users/{id}/toggle):

        Lógica: Si está activo, lo deshabilita y viceversa.

        Retorno: El nuevo botón de estado (Toggle) actualizado.

    Acción: Reset Password (POST /admin/users/{id}/reset-password):

        Lógica: Genera string aleatorio, actualiza DB. Pone la flag must change password en true para que el usuarios ea redirigido a su perfil inmediatamente.

        Retorno: Fragmento con la nueva contraseña temporal visible solo una vez.
